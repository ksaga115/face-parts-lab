# 顔パーツ照合ラボ

「この 2 人、似てない？」を数字で確かめるアプリです。
顔写真を 2 枚入れると、**輪郭・目・眉・鼻・口**のパーツごとに形を測って比べ、どこがどれくらい似ているかを一致率（%）で表示します。

> 🔒 写真はあなたのパソコンのブラウザの中だけで処理されます。インターネット上のどこにも送信・保存されません。

---

## 使い方（3 ステップ）

### 1. アプリを開く

いちばん簡単なのはブラウザで開く方法です。

- **Web 版（だれでも使えます）**: https://ksaga115.github.io/face-parts-lab/

自分のパソコンで動かしたい場合は、下の「[パソコンで動かす](#パソコンで動かす)」を見てください。

右上の 3 つの丸（顔検出 / 478点 MediaPipe / InsightFace）が緑になったら準備完了です。初回はモデル（合計約 50MB）の読み込みに数秒〜数十秒かかります。2 回目からはブラウザのキャッシュで速くなります。

### 2. 写真を 2 枚入れる

「顔 A」と「顔 B」の枠に、それぞれ 1 枚ずつ写真を入れます。入れ方は 3 通りです。

| 方法 | やり方 |
|---|---|
| ドラッグ＆ドロップ | 画像ファイルを枠の上に落とす |
| クリック | 枠をクリックしてファイルを選ぶ |
| 貼り付け | スクリーンショットなどをコピーして `Ctrl + V`（A が空なら A、埋まっていれば B に入ります） |

顔が見つかると、写真の上に顔の線（ランドマーク）が重なって表示されます。写真の下に「68点 ✓ ・ 478点 ✓ ・ InsightFace ✓」と出ていれば、すべての分析が使えます。

### 3. 分析モデルを選ぶ（お好みで）

写真の下の「分析設定」で、使う AI を切り替えられます。切り替えると結果がすぐに計算し直されます。

**顔認識 AI モデル**（顔全体の印象を比べる AI。総合点の 60%）

| ボタン | 特徴 |
|---|---|
| InsightFace（おすすめ） | 新しく大規模なデータで学習したモデル。日本人どうしの比較でも見分けが比較的正確です |
| dlib | 昔からあるモデル。欧米人中心のデータで学習しているため、東アジア人どうしは「似ている」と高めに出やすい傾向があります |
| 2 つの平均 | 両方の平均。モデルごとのクセをならしたいときに |

**顔ランドマーク**（パーツを測るための点。総合点の 40%）

| ボタン | 特徴 |
|---|---|
| 478 点 MediaPipe（おすすめ） | 顔全体を細かいメッシュで捉えます。黒目の大きさ、眉の太さ、鼻の高さ（立体推定）など 34 項目を測れます |
| 68 点 face-api | 標準的な 68 点。26 項目を測ります |

「同じ 2 枚でも AI によって判定がどう変わるか」を見比べるのも面白いです。

### 4. 結果を見る

2 枚とも顔が見つかると、下に結果が出ます。

## 結果の見かた

### 総合一致率

いちばん大きな数字が、2 人がどれくらい似ているかの総合点です。

| 一致率 | 判定 |
|---|---|
| 75% 以上 | よく似ている |
| 55〜75% | やや似ている |
| 35〜55% | あまり似ていない |
| 35% 未満 | 似ていない |

総合点は次の 2 つを合わせたものです。

- **AI 顔認識の類似度（60%）**: 顔認識 AI が感じる「顔全体の印象」の近さ。
- **パーツ形状の一致度（40%）**: 目の大きさ、鼻の幅、顔の縦横比などを実際に測って比べた結果。

「AI は似ていると言っているけど、パーツの形は違う」ようなケースは、文章でも教えてくれます。

### パーツ別スコアとレーダーチャート

輪郭・目・眉・鼻・口の 5 つのパーツそれぞれの一致率です。どのパーツが似ていて、どこが違うかがひと目でわかります。
各パーツの下にある「寸法」はサイズや比率の近さ、「形」は線の形そのものの近さです。

### AI モデルの比較

InsightFace と dlib、両方のスコアが並んで表示されます。右の小さな 2 枚の顔は、InsightFace が実際に見ている画像（目・鼻・口角で位置を揃えて切り抜いたもの）です。

### 似ているところ／違うところ

計測した項目（478 点なら 34 項目、68 点なら 26 項目）のうち、特に近いもの・特に違うものを 5 つずつ挙げます。
違うところには「B の方が面長」「A の方が目の間隔が離れている」のように、どちらがどう違うかが書かれます。

### 重ね合わせ

左側は 2 枚の写真を両目の位置で揃えて重ねたものです。下のボタンで見せ方を切り替えられます。

- **透かし**: B を半透明にして A に重ねる。スライダーで濃さを調整。
- **左右半分**: 左が A、右が B。スライダーで境目を動かせる。
- **差分**: 違う部分ほど明るく光る。

右側は顔の線だけを重ねたものです。青が A、オレンジが B で、灰色の細い線がずれの大きさを表します。

### 計測値の詳細

全項目の数値です。「478点」マークの付いた項目は 478 点モードでだけ測れます。長さは「両目の中心どうしの距離 = 1.00」とした比率なので、写真の大きさや解像度が違っても公平に比べられます。

## きれいに測るコツ

- **正面を向いた写真**を使う（証明写真のようなものが理想）。横を向いていると黄色い注意が出ます。
- **2 枚の条件をそろえる**：表情（真顔どうし）、カメラとの距離、角度が近いほど正確です。
- **顔が大きく写っている**写真を使う。小さいと検出に失敗することがあります。
- 前髪やメガネ、マスクでパーツが隠れていると、その部分の精度が下がります。
- 1 枚に複数人が写っている場合は、いちばん大きく写っている顔が使われます。

## ボタン

| ボタン | はたらき |
|---|---|
| A と B を入れ替え | 左右の写真を入れ替える |
| ランドマーク表示 | 写真の上の顔の線を表示／非表示 |
| 削除 | その枠の写真を消す（別の写真に差し替えたいとき） |

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「顔が見つかりませんでした」 | 顔がもっと大きく、正面に写っている写真を使う。暗い写真も苦手です |
| 「モデルを読み込めませんでした」 | ページを再読み込みする。パソコンで動かしている場合は下の手順でサーバー経由で開いているか確認 |
| ファイルをダブルクリックで開いたら動かない | `index.html` を直接開くと動きません。下の手順で開いてください |
| 「478点 ×」「InsightFace ×」と出る | そのモデルだけ読み込めなかった状態です。残りのモデルで分析は続けられます。再読み込みで直ることがあります |
| 処理がとても遅い | 古いパソコンやグラフィック機能がない環境では時間がかかります。Chrome / Edge の最新版がおすすめです |

## パソコンで動かす

Web 版が使えない環境（社内ネットワークなど）では、このリポジトリを丸ごとダウンロードして、簡易サーバーで開きます。どちらか一方を使ってください。

**Python が入っている場合**

```sh
cd face-parts-lab
python -m http.server 8000
```

**Node.js が入っている場合**

```sh
cd face-parts-lab
npx serve .
```

起動したら、ブラウザで表示されたアドレス（例: `http://localhost:8000`）を開きます。終わるときはターミナルで `Ctrl + C` を押します。

## 注意

- 結果は「見た目がどれくらい似ているか」の目安です。**本人確認・血縁関係の判定などには使えません。**
- 他人の写真を使うときは、その人のプライバシーに配慮してください。

## しくみ（くわしく知りたい人向け）

| 役割 | 使っているもの |
|---|---|
| 顔の検出・68 点ランドマーク・dlib 特徴（128 次元） | [@vladmandic/face-api](https://github.com/vladmandic/face-api) 1.7.13 |
| 478 点ランドマーク | [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker)（tasks-vision 0.10.14） |
| InsightFace 特徴（512 次元） | [InsightFace](https://github.com/deepinsight/insightface) buffalo_s の `w600k_mbf.onnx`（MobileFaceNet / WebFace600K）を [ONNX Runtime Web](https://onnxruntime.ai/) 1.17.3 で実行 |

- dlib 類似度は特徴ベクトルのユークリッド距離を、InsightFace 類似度はコサイン類似度を、それぞれロジスティック関数でスコア化しています（dlib は距離 0.6、InsightFace はコサイン 0.28 で 50%）。
- InsightFace には、68 点ランドマークの両目・鼻先・両口角の 5 点を ArcFace 標準テンプレートに相似変換で合わせた 112×112 画像を入力しています。
- パーツ形状は、両目の位置で顔の傾きと大きさを正規化したうえで、各項目の比率・角度の差と、パーツごとのプロクラステス解析（位置・大きさ・回転を合わせた後の形のずれ）から算出しています。
- 「立体推定」の項目は MediaPipe が推定する奥行き（z 座標）を使っています。1 枚の写真からの推定なので参考値です。
