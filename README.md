# 顔パーツ照合ラボ

2 枚の顔画像を、輪郭・目・眉・鼻・口のパーツごとに比べて一致率を出すブラウザアプリです。
画像はブラウザ内だけで処理され、外部には送信されません。

## 使い方

モデルファイルを `fetch` で読み込むため、`file://` で直接開くと動きません。ローカル HTTP サーバー経由で開いてください。

```sh
npx serve .
# または
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開き、A と B に画像をドロップ（またはクリックで選択 / Ctrl+V で貼り付け）します。

## 分析内容

- **AI 顔特徴の類似度（60%）**: face-api.js の 128 次元特徴ベクトルのユークリッド距離をスコア化
- **パーツ形状の一致度（40%）**: 68 点ランドマークから 26 項目の比率・角度を計測し、パーツごとのプロクラステス解析と合わせてスコア化
- 似ている／違う項目のランキング、レーダーチャート、写真の重ね合わせ（透かし・左右半分・差分）、ランドマークの重ね合わせ

長さは両目の中心間距離を 1.00 とした比率なので、写真のサイズに左右されません。

## 注意

顔の向き・表情・レンズ歪みで結果は変わります。見た目の似ている度合いの目安で、本人確認や血縁判定には使えません。
